Note Taking WebApp.
Frontend Made in React.js (HTML, CSS, JS)
Backend in NodeJS/ExpressJS

Users can take notes, Edit an existing note, Delete notes and toggle between Dark and light mode as per preference.
Next up: User can search among notes with keywords (soon). User Authentication (soon).

## Features:
- Add new notes
- Edit notes
- Delete notes
- Responsive design
- Built with modern react practices

## Tech Stack
- ReactJS
- Vite
- NodeJS
- ExpressJS
- JavaScript (ES6+)
- HTML5
- CSS3
